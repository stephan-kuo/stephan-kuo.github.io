存取的資料

經使用者以 Google 帳號授權後，hermes-stephan-kuo 以唯讀方式存取該帳號的 Gmail 郵件與附件（gmail.readonly）。它不會寄信，也不會修改或刪除郵件。

使用者要求助理閱讀某封郵件時，該郵件內容可能會傳送給使用者自行設定的 AI 模型服務，僅用於完成該次工作。固定排程的下載工作由程式直接執行，不經過 AI 模型。除此之外，資料不提供給任何第三方。

撤銷授權

使用者可隨時至 Google 帳戶的第三方存取權限頁面 移除 hermes-stephan-kuo 的存取權。

hermes-stephan-kuo 使用從 Google API 取得的資訊時，遵守 Google API Services User Data Policy，包括其中的「有限使用」（Limited Use）要求。

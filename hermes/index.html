English

hermes-stephan-kuo is a private assistant tool used personally by Stephan Kuo. It is not a public service and does not accept sign-ups. With the user's authorization, it uses the Gmail API with read-only access to the user's own email, for tasks the user requests such as finding and downloading invoices and receipts. It does not send, change or delete email.

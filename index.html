Assistant Chris

Assistant Chris 是 Stephan Kuo 個人使用的行政助理工具，非公開服務，不對外提供註冊。

經使用者授權後，Assistant Chris 透過 Google Sheets API 與 Google Drive API，讀取與更新使用者指定的試算表，並將使用者要求產生的檔案（例如程序表圖片）上傳至使用者指定的 Drive 資料夾。

English

Assistant Chris is a private administrative assistant tool used personally by Stephan Kuo. It is not a public service and does not accept sign-ups. With the user's authorization, it uses the Google Sheets API and Google Drive API to read and update spreadsheets the user designates, and to upload files the user requests (such as program images) to folders the user designates.
